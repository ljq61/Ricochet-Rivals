# 横版回合制弹道对战网页游戏

## 1. 项目定位

一款横版 2D 回合制弹道对战网页小游戏。

核心体验结合：

- Worms / 百战天虫式双方阵地对抗
- Angry Birds 式拖拽瞄准与抛射
- 可横向拖动查看整个战场
- 每回合有限移动
- 后续加入空中可拾取道具
- 支持单机 AI
- 支持 WebRTC P2P 双人联机
- 不依赖传统游戏服务器

目标平台：

- Desktop Web 优先
- Chrome / Edge / Safari
- 后续兼容手机横屏

推荐技术栈：

- TypeScript
- Vite
- Phaser
- Phaser Arcade Physics 或 Matter.js
- WebRTC DataChannel
- Web Audio API

第一阶段不使用后端数据库。

---

# 2. 核心玩法循环

每个玩家拥有：

- 一个炮手
- 一个己方阵地区域
- 固定生命值
- 当前武器
- 每回合有限移动能力

标准回合：

1. 回合开始
2. 玩家自由查看战场
3. 玩家观察敌方位置
4. 玩家移动自己的炮手
5. 镜头返回己方炮手
6. 玩家拖拽进行瞄准
7. 松手发射
8. 炮弹飞行
9. Camera Follow 炮弹
10. 炮弹碰撞或爆炸
11. 计算伤害
12. 播放效果
13. 同步最终状态
14. 切换玩家
15. 下一回合

玩家每个回合只能发射一次。

# 3. 游戏胜负

双方初始生命值：

10 HP

基础炮弹伤害：

- 直接命中：2 HP
- 近距离爆炸：2 HP
- 中距离爆炸：1 HP
- 爆炸范围外：0

暂定：

0–60px：\
2 Damage

60–140px：\
1 Damage

大于 140px：\
0 Damage

任何一方：

HP <= 0

立即结束比赛。

显示：

胜利 / 失败

提供：

- 再来一局
- 返回主菜单

---

## HOME

镜头平滑移动回当前玩家。

Camera Target：

---

## AIMING

镜头锁定己方炮手附近。

玩家不能拖动地图。

防止：

一边观察敌人，一边在屏幕外操作自己炮手。

---

## PROJECTILE_FOLLOW

发射后：

Camera 自动跟随 projectile。

使用：

smooth follow

而不是完全锁死。

推荐：

lerp 0.08～0.15

这样画面更自然。

---

## IMPACT

炮弹爆炸后：

Camera 保留在爆炸点。

持续：

600～1000ms

显示：

爆炸

伤害数字

角色受击

HP变化

---

## TURN_TRANSITION

下一位玩家回合开始。

Camera 平滑飞向下一位玩家。

然后进入：

FREE_VIEW。

# 7. 瞄准系统

使用 Angry Birds 式反方向拖拽。

操作流程：

鼠标按住角色 / 发射器。

向反方向拖动。

例如：

希望往右上方发射：

玩家向左下方拖。

---

## Drag Vector

```ts
dragVector =
pointerPosition - launcherPosition
```

发射方向：

```ts
direction = -normalize(dragVector)
```

力度：

```ts
power = clamp(
  dragVector.length / maxDragDistance,
  0,
  1
)
```

---

## 最大拖拽距离

建议：

180px

超过以后力度保持 100%。

---

## 最小发射力度

建议：

15%。

低于：

不允许发射。

# 46. 长期最有价值的差异化

游戏的核心不要逐渐变成：

谁武器数值更高。

真正应该强化的是：

“弹道选择”。

一个优秀回合应该让玩家思考：

直接打敌人？

还是吃回血？

还是吃强化？

还是打墙反弹？

还是移动到更好的位置？

因此后续所有机制都应该围绕：

Trajectory Decision

也就是：

弹道决策。

这应该成为整个游戏最核心的设计原则。
