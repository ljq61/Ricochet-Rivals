# Phase 17 美术方向与制作清单

最新已落地批次：[走路、火焰与触角动画](ANIMATION_REFINEMENT.md)；此前为[长支架与标题菜单精修](DOCK_MENU_REFINEMENT.md)和[概念对齐与特效重制](PHASE17_POLISH_REWORK.md)。下文素材帧数为初始建议，当前走路采用双角色各 8 帧序列，受击与后坐仍采用程序动画。

日期：2026-09-29。用户随后确认执行首屏样片；已生成并接入海港远景、双角色静态姿态和塔楼。实际交付见 [FIRST_LOOK_ASSETS.md](FIRST_LOOK_ASSETS.md)。本文尺寸和帧数仍是完整素材批次的建议，未全部制作。

## 1. 参考与视觉目标

- `concept01`：PNG，1672 × 941；战斗构图、角色、武器、特效、场景及横屏 HUD 的风格参考。
- `concept_UI.png`：PNG，1672 × 941；标题、模式选择、联机、加载及设置界面的风格参考。

目标是高密度像素插画风的海岛工业战场：晴蓝天空、暖色积云、远处海岛与废弃船厂；前景使用旧钢板、铆钉、管道、支架与旗帜。角色比例偏卡通，护目镜与大武器形成轮廓。P1 使用蓝队识别，P2 使用红队识别。

视觉层级：可交互按钮和角色优先，其次是弹道与爆炸，最后才是环境细节。远景降低对比与饱和度；角色附近不放与角色同亮度、同轮廓的密集装饰。避免用整张概念拼图充当游戏界面。

建议色板（人工提案，非参考图采样）：

| 用途 | 颜色 |
| --- | --- |
| 深色 UI 底板 / 描边 | `#151C22` / `#080D12` |
| 钢铁中间色 / 边缘高光 | `#465360` / `#B4B6AD` |
| 主按钮 / 高光 | `#F3A725` / `#FFE19A` |
| P1 / P2 | `#43A9DB` / `#E94B48` |
| 天空 / 暖云 | `#477DB0` / `#EDC18C` |
| 正文 | `#F5EAD2` |

文字保持清晰；像素感主要来自插画轮廓、材质和图标。按钮文字、HP、回合和连接状态由程序实时绘制，不烘焙进贴图。标题拼写统一为 **RICOCHET RIVALS**，已在首屏接入时修正。

## 2. 本轮范围

### 使用已有功能的美术替换

- 主菜单三个模式入口、声音开关、全屏入口。
- 单一战场、蓝红双方角色、NORMAL 投射物、弹道预览、爆炸、伤害数字。
- 双方 HP、回合提示、现有移动 / 瞄准 / 镜头控制。
- 当前手动连接码配对、准备状态、断线提示和结算 / 再战界面。

### 参考中暂不制作成可用功能的部分

风力、多武器背包、空投、道具、排行榜、公告、账号、房间列表、房间密码、地图选择和自动重连均不是本轮美术接入的前置要求。参考图的独立标题页与模式选择页可先合并到现有 MainMenuScene；联机皮肤必须保留真实的连接码流程，不能出现没有数据来源的房间列表。

Phase 17 的完整范围另含发射 / 飞行 / 爆炸 / 命中 / 回合 / 胜负音效、粒子和 hit stop。美术首批完成不等于整个 Phase 17 完成。

## 3. 已核对的实现约束

| 当前事实 | 对美术的约束 |
| --- | --- |
| 世界 5000 × 1080，地面顶 Y=960 | 场景分层制作，适配横向相机移动；不能将 16:9 全景拉伸覆盖地图 |
| P1 出生 X=450，P2 出生 X=4550 | 两侧基地分别制作，保留角色和镜头的活动空间 |
| 双方移动区 X=100–850 / 4150–4900 | 装饰不能被误认为新增可碰撞障碍；脚下地面要连续清晰 |
| 玩家碰撞体 120 × 180，脚底是视觉定位基准 | 所有角色帧脚底锚点一致；角色可见高度约 180 世界像素，碰撞体与视觉脚底对齐 |
| 发射原点 Y 偏移 -64；炮弹半径 16 | 武器表现要对齐真实发射点；弹体可读轮廓接近碰撞尺寸 |
| 10 HP，直伤 2 / 溅射 1，伤害半径 140 | HUD 显示真实数值；爆炸装饰尺寸不作为伤害范围依据 |
| 鼠标 / 触屏反向拖拽，松手发射 | 不照搬概念图里的第二套独立发射操作 |
| ViewportService 已处理 DPR、Safe Area、缩放 | 沿用现有坐标链，避免换皮后可见按钮与命中区错位 |
| Host 权威结算，Guest 播放表现 | 特效不改变 GameState、物理步长、网络超时或回合授权 |

## 4. 首批素材交付规格（建议）

先做静态样片，在真实游戏尺寸下确认清晰度，再扩动画。表中尺寸为素材画布尺寸；角色最终显示比例需要结合 120 × 180 的碰撞体和脚底锚点调校，不能按贴图尺寸直接显示。

| 批次 | 素材 | 建议规格与验收要点 |
| --- | --- | --- |
| A | 主菜单背景 1 张 | 1920 × 1080；无文字、无按钮；中心留模式入口空间，边缘可裁切 |
| A | 战场天空 / 远岛 | 独立图层，建议各 2048 × 1024；远景可循环或用多段拼接，接缝需实测 |
| A | 左右基地各 1 张 | 1024 × 1024 透明 PNG；基线统一，蓝红识别，装饰不遮挡活动区 |
| A | 地面模块 1 组 | 512 × 128 透明 PNG；顶部行走线平直，横向无缝，左右端帽分离 |
| A | 双方角色 chibi 静态样片 | 每个透明 PNG；二头身 Q 版、脚底锚点统一、统一像素密度；面向右，允许镜像 |
| A | 双方头像各 1 张 | 128 × 128；紧凑头肩构图，蓝红边框由 UI 绘制 |
| A | NORMAL 弹体 1 张 | 64 × 64 透明 PNG；紧凑榴弹轮廓，旋转中心居中 |
| A | UI 基础皮肤 | 普通 / 悬停 / 按下 / 禁用四态；金黄主按钮、深钢副按钮、面板、血条底框；拉伸区与四角分开 |
| B | 双方角色动画 | idle 4 帧、run 6 帧、aim 1 帧、fire 3 帧、hit 2 帧、win 4 帧、defeat 2 帧；统一画布与脚底线 |
| B | 爆炸与粒子 | 爆炸建议 256 × 256 × 8 帧；火星 / 烟 / 碎片独立小纹理；不带文字与地面 |
| B | 弹道 / 瞄准图标 | 高亮点、准星、方向箭头；浅色核心加深色边，晴空和基地前均可读 |
| C | 联机 / 结算装饰 | 复用面板和角色；连接中、准备、断线、胜负各有可辨状态 |
| C | Logo | 透明 PNG，建议 1024 × 384；文字单独复核；狭窄横屏保留简化标题方案 |

PNG 透明区域必须是真 alpha，不含棋盘格或黑色烘焙底。动画不能用不等宽的概念姿态拼贴直接当 spritesheet。先统一轮廓、光源、脚底锚点和帧格，再导出。

建议分层制作源文件保留在本目录的 `sources/`；当前生成原图及运行时资产已放入 `public/assets/art/`，尚无分层工程。每批记录文件名、用途、源文件、制作方式 / 来源、授权说明、画布尺寸、显示尺寸、锚点及状态。概念参考不等于可直接拆图发布的正式素材。

## 5. 接入位置与顺序

1. **单屏风格样片**：先做菜单背景、双方 idle、背景分层与基础 UI；在实际主菜单和战斗构图中评估，不先批量制作所有动画。
2. **基础资源加载**：在 `BootScene.ts` 增加预加载与必要加载反馈；资源 key 保持稳定。加载失败要有可读提示或现有占位回退。
3. **场景与实体**：`WorldBuilder.ts` 替换环境；`Player.ts` 替换角色视觉；`Projectile.ts` 替换弹体和爆炸。保留物理尺寸、状态流和镜头控制。
4. **界面**：`Palette.ts`、`MenuButton.ts`、`PlayerHud.ts`、`TurnBanner.ts`、`AimButton.ts`、`AimRenderer.ts` 统一皮肤；再覆盖 MainMenu / OnlineConnection / Result 三类场景。继续使用 InputRouter 热区。
5. **反馈升级**：已有震动、受击闪烁、血条动画和菜单淡入淡出先复用。粒子、角色反应与音效接入真实事件；同一爆炸不能在预测和权威结果到达时重复播音。
6. **hit stop 单独处理**：仅冻结或强调表现，不直接暂停 Matter、网络或全局时钟。接入前核对 Host / Guest 的事件时序，并验证连续再战时资源清理。

场景销毁必须清理自建音频节点、粒子、Tween 和订阅；不得将资源管理与表现逻辑堆进 BattleScene。最近的联机收尾约束仍适用：退出路径清理一致、使用会话前检查连接状态。

## 6. 验收与进度口径

- 美术：主菜单、战场、联机、结算分别截图；与两张参考对照检查色调、轮廓、材质、视觉层级。必须实看游戏截图，不能只看素材大图。
- 构图：桌面 16:9 与手机横屏至少各一组；检查安全区、HP / 回合信息、触控按钮和角色大小，横拖整个战场没有背景空洞。
- 操作：进入三种模式、移动、拖拽瞄准、发射、命中、回合切换、返回菜单及再战；确认皮肤热区与画面重合。
- 联机：双端爆炸 / HP 一致；视觉反馈不影响权威快照、断线处理或再战；音效开关真实生效。
- 工程：正式代码接入后运行 typecheck、相关单测、build 与对应 E2E；文档准备阶段不声称通过运行时验收。
- 性能：以现有版本为基线对比帧率、纹理占用及加载时间；远景复用，禁止每帧创建整张背景纹理。
