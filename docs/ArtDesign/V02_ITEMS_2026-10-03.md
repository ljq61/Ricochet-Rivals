# V0.2 道具美术与 HUD 反馈

日期：2026-10-03。参考：[concept01.png](concept01.png)。使用内置 `image_gen`，透明背景 PNG；两张生成原图复制到项目，游戏无需访问生成目录。

本轮反馈：蓝方道具在左、红方在右；去掉 BLUE CREW / RED CREW、血条外部整块底框、头像下与角色头顶的 P1/P2，血条上移。瞄准按钮保持原位置。追加反馈将道具固定在同侧边缘垂直居中，改由移动按钮避让道具；移动箭头缩小，可见尺寸不超过 52 CSS px，点击区至少 48 CSS px。血条保留原来的暗色内槽、金属细边、分段高光与阴影，仅去掉外部整块大框。设置按钮兼顾短屏、安全区与血条避让。

## 完整生成提示词

两次调用均传入 `concept01.png` 作为风格参考，并设置 `transparent_background: true`。

### 降落伞木箱

```text
Use case: stylized-concept. Create a NEW game sprite, using the supplied concept01 solely as visual style reference. A single parachute supply wooden crate for the 2D side-view artillery game Ricochet Rivals. Actual transparent alpha background. Golden khaki canvas domed parachute above a square front-facing weathered honey-brown wooden crate with brass reinforced corners and visible plank seams, four thin dark suspension ropes. Match reference hand-painted detailed pixel-art maritime dieselpunk style, bold dark outline, crisp readable edges, warm brass highlights. Full object centered with 6% transparent margin, silhouette fully visible, no shadow outside object. The wooden crate occupies bottom 38 percent, parachute and ropes the upper 62 percent. CRATE FRONT MUST BE BLANK with a dark square mounting plaque so runtime can overlay an item badge. Orthographic frontal sprite, absolutely no scene, no people, no lettering, no HUD, no extra objects, no black or white backdrop. Output a transparent PNG suitable as a game asset.
```

### 道具栏图集

```text
Use case: stylized-concept. Create ONE production game UI SPRITE ATLAS, a precisely regular 2-column by 3-row grid, six equal square cells, isolated transparent alpha everywhere between and behind sprites, NO text or numbers, no scene. Use provided Ricochet Rivals concept01 as visual style reference only: crisp richly shaded hand-painted pixel-art, warm brass rims, dark steel inserts, bold readable silhouettes. Each cell contains ONE centered complete square brass-and-steel riveted button bezel of IDENTICAL size occupying 80 percent of cell width and height, leaving 10 percent transparent margin. Top-left cell: healing icon, ivory medical kit with bright green cross. Top-right: damage boost, chunky orange-red cannon shell with gold lightning emblem. Middle-left: blast range boost, cyan-blue expanding explosion ring emblem. Middle-right: homing aim, gold telescopic target reticle with central red dot. Bottom-left: inventory bag, brown leather field satchel with brass clasp. Bottom-right: empty slot, empty dark steel inset with brass border, absolutely no symbol. All buttons front-facing orthographic, aligned exact regular grid, no shadows outside sprites, no perspective, no letters, no labels, no HUD screenshot, no extra objects. Transparent PNG atlas suitable for runtime slicing into six frames. Preserve clear silhouettes at 52 CSS px.
```
